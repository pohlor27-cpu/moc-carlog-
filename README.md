# 🚗 MOC Car Log - ระบบบันทึกการใช้รถราชการ (แบบ 4) อัจฉริยะ

ระบบบันทึกเวลาออก-กลับรถราชการ ออกแบบมาเป็นพิเศษสำหรับ **พนักงานขับรถ (ผขร.) 4 คน** ใช้งานง่ายสุดๆ ไม่ต้องพิมพ์เยอะ พร้อมระบบ AI อ่านเลขไมล์จากรูปถ่าย และสั่งพิมพ์เอกสาร **"แบบฟอร์ม 4"** ตรงตามมาตรฐานราชการ 100%

---

## 🌟 ฟีเจอร์เด่น

1. **ผขร. แตะ 3 ปุ่มจบ:** 
   - แตะเลือกรูปชื่อตนเอง (ผขร. 4 คน)
   - กด `[บันทึกเวลาออก]` หรือ `[บันทึกเวลากลับ]`
   - ถ่ายรูปหน้าปัดไมล์ -> AI เติมเลขไมล์และเวลาให้อัตโนมัติ
2. **ปุ่มกดสถานที่ด่วน (Quick Chips):** แตะเลือกสถานที่ยอดฮิต เช่น ศาลากลาง, กระทรวงพาณิชย์, ตรวจตลาดสด ได้ทันที
3. **คำนวณระยะทาง & น้ำมัน Auto:** คำนวณระยะทาง (กม.) และสรุปยอดประจำเดือนอัตโนมัติ
4. **พิมพ์แบบ 4 ราชการ 1:1:** กดปุ่มเดียว `[🖨️ พิมพ์แบบ 4 (ราชการ)]` แปลงเป็นตารางเอกสารพร้อมพิมพ์/เซ็นชื่อทันที

---

## 🚀 วิธีรันบนเครื่องติ๊น้อย (Local Development)

```bash
cd ~/moc_phetchaburi_agent/car\ log
python3 server.py
```

- เปิดเบราว์เซอร์เข้าที่: `http://localhost:8088`
- หากต้องการเปิดจากมือถือในวง Wi-Fi เดียวกัน: `http://192.168.1.36:8088`

## ☁️ ขั้นตอนการนำขึ้น Cloud 24 ชม. ฟรี (Option 1)

เมื่อทดสอบบนเครื่องติ๊น้อยเรียบร้อย สามารถนำขึ้น Cloud (เช่น **Vercel** หรือ **Render**) เพื่อให้ ผขร. ใช้งานได้ตลอด 24 ชั่วโมง โดยไม่ต้องเปิดคอมทิ้งไว้:
1. สร้างโปรเจกต์บน Vercel / Render
2. ตั้งค่า Database ด้วย Supabase (PostgreSQL Cloud ฟรี)
3. ใส่ `GEMINI_API_KEY` ใน Environment Variables เพื่อเปิดระบบ AI Vision เต็มรูปแบบ
